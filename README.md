# Pawfect Pet Care

**Author: ** Recep Sen

## Description
A responsive single-page website for Pawfect Cat Care built using Bootsrap 5. it features a sticky navigation bar, an image carousel of our cat hotel suites, service cards for daycare, grooming, and boarding, and an interactive FAQ accordion.
